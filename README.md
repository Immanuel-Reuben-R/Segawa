# Segawa AI Assistant

A locally hosted, self-learning personal AI assistant built with Python, JS, and CSS.

## Goals
- Chatbot interface for "Segawa".
- Hybrid learning: Uses Retrieval-Augmented Generation (RAG) for perfect memory, while logging data for future fine-tuning.
- Completely free (no paid APIs).
- Fully local storage and execution optimized for 8GB RAM / 8GB VRAM (AMD).
